Scenario 5 • Contact

This page is used to test a simple contact form. The script fills in the name and message fields using broken locators first, then relies on the auto-healing logic to find the real elements.

Name field Message field Send button
Step 1 • Fill in the form

Contact form

The test types a name, enters a short message, and then clicks the send button. All three locators can be “broken” in the test script, so healing must resolve them to these real IDs.

Target locators: id="contact_name", id="contact_message", and id="send_message_btn".

What the test checks here

Healing goals on this page

  • Can the name input be found when its locator in the test is wrong?
  • Can the message textarea still be located after ID changes?
  • Can the “Send message” button be healed and clicked reliably?
